# Clickie User Manual

Official guide to the Clickie platform for data operation, metrics, monitoring, viewer, dashboards, assets and digital twins.

## Who is this manual intended for?

This manual is written for operations teams, analysts, business leaders and clients who need to quickly understand what the platform can solve and how to take it to production.

The goal is not just to show screens: it is to explain decisions, configuration criteria and expected results in each module.

## Basic principle of the platform

:::intro-principle icon="◆"
Everything at Clickie is built from **metrics**. Each metric represents a time series of data that evolves over time and serves as a basis for:
:::

- Monitoring
- Dashboards and reports
- Data viewer
- Digital twins
- Assets

When the metrics layer is well defined, the rest of the modules become predictable, reusable, and scalable.

## General interface structure

The main interface includes:

1. Side menu with functional modules.
2. Global search engine for metrics, assets, panels, reports, monitoring and digital twins.
3. User profile for account and language settings.

## Recommended learning path

:::learning-path title="Camino de aprendizaje recomendado"
1. **Understand metrics**: Understand what a metric is, how it is recorded and what data quality it has.
2. **Select and Combine**: Learn to choose metrics, apply labels, and build useful formulas.
3. **Validate in Viewer**: Contrast trends, ranges and visualizations before publishing results.
4. **Automate with Monitoring**: Define rules and triggers to go from analysis to operational action.
5. **Communicate in panels**: Turn findings into executive reading for teams and clients.
6. **Model with Twins**: Bring the visual context of the asset to accelerate interpretation and decisions.
:::

## What result should you expect

If you follow the path in this manual, you should be able to:

- move from raw data to operational decisions,
- standardize criteria between teams,
- reduce diagnosis times,
- and better communicate the value of data to customers and stakeholders.
