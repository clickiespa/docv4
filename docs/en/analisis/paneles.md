# Dashboards and reports

The **Panels and Reports** module allows you to build persistent visualizations for operational monitoring and periodic analysis.

## Listing data

Each listing item includes:

- Panel name
- Panel type
- Creation date and time
- Actions available

## Common Stock

- **View**: opens the panel or report with its widgets.
- **Information**: shows metadata (ID, dates, etc.).
- **Modify**: allows you to edit settings.
- **Archive**: Hides the main listing panel without deleting it.

## Filters available

- Type: Classic
- Type: Report
- Archived/not archived
