# Account settings

The **Account Settings** section centralizes the management of collaborators, account data and appearance.

## Account management

Includes:

- Collaborators (view, modify, delete)
- Account details
- Time zone
- Dashboard for home

## Account appearance

Allows you to adjust:

- Site name
- Descriptive text
- Welcome header
- Tab icon
- Clickie subdomain
- Authentication logo and authentication image
- Internal logo
- Brand color
