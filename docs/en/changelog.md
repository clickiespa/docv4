# Changelog

## 2026-03-16

- The **API v4** section was incorporated into the `mkdocs.yml` navigation, including a nested structure by endpoint domains.
- Visibility of `docs/api/**` was enabled both in MkDocs and on the public website generated by React/Vite.
- Bilingual version was created for the public website:
  - `docs/api-es/**`: Spanish translation of the original unmodified `docs/api/**` API documentation.
  - `docs/en/**`: English translation of the functional documentation.
- Language selector (ES/EN) was added to the topbar, with the default language being Spanish and preference persistence in the browser.
- Added `scripts/build_bilingual_docs.py` to automatically regenerate translated folders.

## 2026-02-26

- Comprehensive spelling review of the documentation in `/docs` (accentuation, diacritical accents and editorial consistency in titles and contents).
- Alignment of visible texts of the generated website (`scripts/generate_web_docs.mjs`) to maintain consistent spelling with the Markdown font.
- Spelling adjustments to `README.md` and navigation to `mkdocs.yml` (without altering paths or file names).

## 2026-02-25

- Incorporation of the complete **Bulletins** documentation in `configuracion/`:
  - `boletines.md`
  - `boletines-bloques.md`
  - `boletines-grupos.md`
  - `boletines-plantillas.md`
- Restructured `mkdocs.yml` to nest Newsletters within a single navigation menu.
- Adjusted `scripts/generate_web_docs.mjs` to support nested navigation in the web sidebar.
- Updated `src/App.jsx` and `src/manual.css` to enable and style nested links.
- Usability improvement: Bulletin submodules collapsed by default and expand/collapse toggle when clicking on the group name.
- Incorporation in `automatizacion/monitoreos.md` of a practical example of power factor monitoring (`F. de Pot.`) with a web-only visual scheme in three steps: Monitoring, Rule and Trigger.
- Formalized editorial rule: each change in documentation must register its entry in this changelog with date (`YYYY-MM-DD`).

## 2026-02-23

- Reorganization of documentation by domains (`conceptos`, `analisis`, `automatizacion`, `modelado`, `organizacion`, `configuracion`).
- Incorporation of editorial frontmatter in all Markdown documents.
- Updated `mkdocs.yml` for semantic navigation.
- Adjusted `scripts/sync_to_gdocs.py` to ignore frontmatter and respect `nav` order.
