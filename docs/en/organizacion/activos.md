# Assets

The **Assets** module organizes metrics, dashboards and twins under a common logical unit to improve navigation and operational context.

## Listing data

For each asset, the following is displayed:

- Name
- Category
- Creation date
- Actions available

## Asset detail sections

- **Summary**
- **Subactive**
- **Metrics**
- **Digital twins**
- **Facilities**
- **Documents**
- **Activity**
