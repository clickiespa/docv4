# Selector de metricas

El **Selector de metricas** es una herramienta transversal para elegir y configurar datos en cada contexto de uso.

## Donde se usa

- Paneles y reportes
- Visor de datos
- Monitoreos
- Formulas de calculo

## Capacidades principales

- Explorar metricas por activos, instalaciones, UOM y etiquetas.
- Personalizar nombre, color, resolucion, agregacion e interpolacion sin alterar la metrica original.
- Crear metricas virtuales mediante etiquetas.
- Crear metricas calculadas usando IDs en formato `@numero`.
