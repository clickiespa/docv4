# Conceptos

Sección base para comprender cómo se estructura la información en Clickie y por qué esa estructura impacta directamente en la calidad de análisis y automatización.

## Por qué empezar por aquí

Antes de crear un monitoreo, un panel o un gemelo digital, es clave alinear lenguaje y criterios sobre métricas.

Esta sección busca que todos los perfiles (técnicos y de negocio) compartan la misma base conceptual para evitar configuraciones inconsistentes y reprocesos.

## Alcance

- Definición de métricas y su ciclo de vida.
- Uso del Selector de métricas como herramienta transversal.
- Fundamentos para fórmulas, monitoreos y visualizaciones.
- Criterios para pasar de exploración a operación.

## Resultado esperado

Al completar esta sección deberías poder:

- identificar la métrica correcta para cada caso,
- configurar parámetros sin afectar el dato original,
- construir primeras combinaciones y cálculos,
- y dejar una base lista para los módulos de Análisis, Automatización y Modelado.
