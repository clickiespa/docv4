# Conceptos

Seccion base para comprender como se estructura la informacion en Clickie y por que esa estructura impacta directamente en la calidad de analisis y automatizacion.

## Por que empezar por aqui

Antes de crear un monitoreo, un panel o un gemelo digital, es clave alinear lenguaje y criterios sobre metricas.

Esta seccion busca que todos los perfiles (tecnicos y de negocio) compartan la misma base conceptual para evitar configuraciones inconsistentes y reprocesos.

## Alcance

- Definicion de metricas y su ciclo de vida.
- Uso del Selector de metricas como herramienta transversal.
- Fundamentos para formulas, monitoreos y visualizaciones.
- Criterios para pasar de exploracion a operacion.

## Resultado esperado

Al completar esta seccion deberias poder:

- identificar la metrica correcta para cada caso,
- configurar parametros sin afectar el dato original,
- construir primeras combinaciones y calculos,
- y dejar una base lista para los modulos de Analisis, Automatizacion y Modelado.
