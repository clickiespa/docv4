# Visor de datos

El Visor de datos funciona como una caja de arena para explorar metricas antes de consolidarlas en paneles y reportes.

## Casos de uso

- Probar una metrica en distintos rangos de tiempo.
- Comparar series en una misma vista.
- Evaluar resolucion, agregacion e interpolacion.
- Preparar visualizaciones para reportes ejecutivos.

## Flujo sugerido

1. Seleccionar metricas con el selector.
2. Ajustar parametros de analisis.
3. Validar tendencia y consistencia de datos.
4. Exportar o promover a panel/reporte.

## Tipos de visualizacion comunes

- Serie temporal
- Barras
- Tabla
- Indicadores resumidos

## Exportador de datos

Desde el Exportador de datos se puede descargar informacion en formatos de intercambio para analisis externo.

Campos habituales de configuracion:

- Rango de fechas
- Conjunto de metricas
- Resolucion
- Formato de salida
