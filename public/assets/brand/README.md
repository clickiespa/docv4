La cabecera usa la versión blanca sobre fondo oscuro. El pie de las versiones
HTML legadas usa la versión gris sobre fondo claro. El favicon usa el logo
completo oficial: gris por defecto y blanco cuando la pestaña indica esquema
oscuro. No se recorta, recolorea ni recrea un isotipo.

La proporción y el espacio interior definidos por el SVG se conservan con
`height: auto`. La fuente de la aplicación es `scripts/generate_web_docs.mjs`;
`src/manual.generated.html` se regenera durante el inicio y la compilación.
