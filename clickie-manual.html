Capítulo 1

Introducción

Conceptos fundamentales de la plataforma Clickie
◆
Todo en Clickie se construye a partir de métricas. Comprender qué es una métrica, cómo se genera y cómo se utiliza es el primer paso —y el más importante— para aprovechar el resto de las herramientas de la plataforma.

La plataforma Clickie está diseñada para transformar datos en información útil para la toma de decisiones. Para lograrlo, propone un enfoque claro y estructurado centrado en las métricas como elemento central de toda la experiencia.

¿Qué es una métrica?

DEFINICIÓN
Serie temporal de datos
Una métrica en Clickie representa una sucesión de valores que se registran y almacenan a lo largo del tiempo. Cada valor corresponde a una medición realizada en un momento determinado y refleja el comportamiento de una variable del mundo real.
Ejemplos de variables
Consumo de energía Temperatura Caudal de agua Flujo de personas Estado de un equipo Y muchas más...

Desde el instante en que una métrica comienza a registrar datos, se convierte en una línea de tiempo en constante crecimiento, que va desde el inicio de la medición hasta el momento presente.

Clickie almacena la información de forma estructurada a través de estas métricas. No importa si los datos provienen de sensores físicos, dispositivos instalados en terreno, sistemas externos o cálculos internos: todo dato que ingresa a la plataforma lo hace en forma de métrica. Por este motivo, las métricas constituyen la fuente primaria de información y el pilar fundamental sobre el cual se apoyan todas las demás funcionalidades del producto.

Herramientas que se construyen sobre las métricas

A partir de las métricas, la plataforma habilita distintas herramientas que permiten analizar, visualizar y accionar sobre los datos:

Monitoreos
Observan ventanas de tiempo específicas de una o más métricas y verifican si sus valores cumplen con condiciones definidas por el usuario. En función de esas condiciones, el sistema determina estados (OK, advertencia, alarma, etc.) y puede ejecutar acciones automáticas.
Paneles y reportes
Utilizan métricas para construir visualizaciones persistentes que facilitan el análisis periódico de la información, combinando gráficos, tablas e indicadores.
Visor de datos
Funciona como un entorno de exploración o "caja de arena", donde el usuario puede probar distintas métricas, combinarlas, ajustar parámetros y experimentar con visualizaciones antes de decidir qué información desea conservar en un panel.
Gemelos digitales
Representan visualmente activos reales y muestran, en tiempo real, valores provenientes de métricas superpuestas sobre esquemas o imágenes.
Activos
Permiten organizar métricas, paneles y gemelos digitales bajo una misma unidad lógica, facilitando el acceso y la comprensión de la información.

El selector de métricas — herramienta transversal

Un componente clave en toda la plataforma es el selector de métricas, una herramienta transversal que aparece cada vez que el usuario necesita elegir datos para una visualización, un monitoreo o un cálculo. Este selector no solo permite navegar por las métricas disponibles según distintas estructuras lógicas (activos, instalaciones, unidades de medida, etiquetas), sino que además habilita la personalización del uso de las métricas en cada contexto, sin modificar los datos originales.

A través del selector de métricas, el usuario puede:

Ajustar parámetros de visualización
Modificá agregación, interpolación, resolución o nombre para cada uso específico, sin alterar la métrica original.
Crear métricas virtuales
Mediante etiquetas, combiná múltiples métricas reales en una sola serie temporal unificada.
Definir fórmulas de cálculo
Generá nuevas métricas derivadas a partir de operaciones matemáticas entre métricas existentes o valores constantes, usando el ID (@número) de cada métrica. Estas capacidades permiten que Clickie no solo registre datos, sino que los convierta en información flexible, adaptable y significativa según las necesidades de cada usuario.

Fórmulas de cálculo

Métricas calculadas bajo demanda con operadores matemáticos e IDs de métricas
Las métricas calculadas se obtienen aplicando una fórmula sobre otras métricas. Se calculan bajo demanda: el sistema resuelve la fórmula para el rango de fechas pedido. Usá el ID (@número) de cada métrica para construir la fórmula. La estructura debe ser lógica para obtener resultados consistentes y trazables.
Ejemplos de fórmulas
FórmulaDescripción
@111-@111[-1]Diferencia de consumo respecto a la lectura anterior
(@222+@333)/2Promedio de potencia de dos generadores
@444/1000Convierte de watt-hora a kilowatt-hora
pow(@555,2)/@666Voltaje al cuadrado sobre resistencia
(@777>5000)?5000:@777Limita el consumo a 5000 cuando supera ese valor
(@888>0)?@999:@111Si la métrica 888 es positiva usa la 999; si no, la 111
(@111>0)?@111:falseElimina valores negativos — false deja vacío (distinto de 0)
(@222>1000)?(@333>500?@333:@444):@555Condicional anidado para elegir entre varias métricas

Definición de los conceptos clave de la plataforma
Activo
Elemento físico o lógico que genera datos dentro de la plataforma.
Agregación
Método utilizado para resumir o consolidar datos en un intervalo de tiempo.
Archivar
Acción de ocultar un elemento sin eliminarlo de la plataforma.
Disponibilidad
Determina cómo se completan los datos faltantes cuando una métrica participa en un cálculo.
Fuente de métrica
Origen del dato: dispositivo, sistema externo, cálculo interno, API, etc.
Gemelo digital
Representación virtual de un activo real, con sus datos y comportamiento mostrados en tiempo real.
Interpolación
Método para completar valores faltantes entre puntos de datos conocidos.
Métrica

Monitoreo
Proceso que evalúa condiciones o umbrales sobre métricas para generar eventos y alertas automáticas.
Panel
Espacio visual que agrupa gráficos, tablas y widgets para el análisis de datos.
Selector de métricas
Herramienta transversal que aparece cada vez que el usuario necesita elegir métricas para una visualización, monitoreo o cálculo.
Visualización
